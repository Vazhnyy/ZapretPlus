# Zapret+

Лаунчер стратегий **zapret** на Python и CustomTkinter с тёмной палитрой в стиле Material You, настройкой цветов каждого элемента, поиском по спискам доменов/IP и автозагрузкой.

## Скачать
Скачайте готовый файл **`ZapretPlus.exe`** в разделе **Releases** на странице репозитория и запустите его.
